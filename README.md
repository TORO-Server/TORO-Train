# TORO-Train

Display エンティティで描く列車の Paper プラグインです。TrainCarts と同じように、線路と看板で駅・分岐・発車などを制御でき、ワールドのブロックをそのまま列車にして走らせることもできます。

TrainCarts のコードは使わず、Kotlin で一から作っています。

## 動作環境

- Paper 26.3
- Java 25

## TrainCarts との違い

- **バニラのトロッコを使いません。** 列車はプラグインの中だけにあり、線路の上の位置 (先頭からの道のり) で動きます。見た目はブロック・アイテム・文字のディスプレイで描き、移動と回転はディスプレイの補間で滑らかにします。
- **車両は線路の上の 2 点 (前後の台車) を結んだ向きに置きます。** 長い車両でもカーブで線路からはみ出しにくく、坂では傾きます。
- **後ろの車両は、先頭が通ってきた道をそのままたどります。** 分岐の形が後から変わっても、後ろの車両だけ別の線路に入ることはありません。
- **エンティティはワールドに保存しません。** 列車の状態は `trains.yml` に保存し、チャンクが読み込まれたときに見た目を作り直します。サーバーが落ちても、ワールドに部品のエンティティが残りません。
- **信号 (blocker) や排他区間 (mutex) は、列車が先の線路を調べて手前で止まります。** 看板の上に来てから急に止まるのではなく、減速して止まります。

## 使い方

### 列車を出す

- トロッコのアイテムを線路に置くと、TORO-Train の列車になります (`train.replace-minecart` で切り替え)。
- `/tt create [両数] [ブロック]` で、見ている線路に列車を出します。
- `/tt save <名前>` で今の列車を保存し、`/tt spawn <名前>` や `spawn` の看板で何度でも出せます。

### 乗る・運転する

- 車両を右クリックすると、近くの空いている座席に座ります。しゃがむと降ります (降りられない設定にもできます)。
- 運転席 (先頭か最後尾の車両の、いちばん前かいちばん後ろの座席) では、**W で力行 (P1 - P5)、S でブレーキ (B1 - B7、非常)** のマスコンになります。止まっていて非常ブレーキのときにもう一度 S を押すと、進む向きが反対になります。ジャンプで警笛を鳴らします。
- 画面の下に、ノッチ・速さ・最高速度・行き先が出ます。
- しゃがんで車両を叩くと、列車を消します (自分の列車だけ。管理者はすべて)。しゃがまずに叩くと、その列車を選びます。

### 速さの書き方

数字だけなら「ブロック/tick」です (0.4 = 28.8 km/h)。`60km` (km/h) や `10m/s` とも書けます。

## 走れる場所

| 場所 | 走り方 |
| --- | --- |
| レール (ふつう・パワード・ディテクター・アクティベーター) | 形のとおりに走る。動力の入ったパワードレールで加速し、入っていないパワードレールで止まる。ディテクターレールは列車がいるあいだ信号を出す |
| 感圧板 | まっすぐなレールとして走る。南北だけに線路があれば南北、東西だけなら東西、両方ある・どちらもないなら十字路になり、入ってきた向きのまま抜ける。木の感圧板と重量感圧板は列車がいるあいだ入る (石の感圧板は生き物にしか反応しないので入らない) |
| ハシゴ | 真上・真下に走る。車体は床を壁に向けて上り下りし、上りでは重力で遅くなり、下りでは速くなる |
| 自由な線路 | 下の「自由な線路」 |
| 線路の外 | 線路の終わりで止まらずに外れて進む (`derail` の設定)。重力で落ち、ブロックに当たると止まり、地面では滑って遅くなる。線路の近くを通るとその線路に乗る |

ハシゴは次のようにつなぎます。

- **下**: ハシゴの 1 つ下のブロックに、壁に向かうレールを置きます。平らなレールでも、壁に向かって上る坂でもつながります。
- **上**: ハシゴを付けた壁の上にレールを置くか、いちばん上のハシゴの真上にレールを置きます。
- **看板**: ハシゴを付けた壁の裏 (壁をはさんでハシゴの反対側) に置くか、壁の横に貼ります。

線路の終わりの先が壁なら、外れた列車は壁に当たって止まり、線路の上に戻ります。線路の終わりで外れずに止めたい列車は、`derail` を `false` にしてください。

## 看板

線路の **下のブロックのさらに下** に置くか、**線路の下のブロックの横** に貼ります (線路の真下に置くと、線路が支えを失って壊れます)。ハシゴの看板は上の「走れる場所」のとおりです。

```
1 行目: [train] (列車全体) / [cart] (車両ごと)
         [+train] は信号があるときだけ、[!train] は信号がないときだけ働く
2 行目: 看板の種類
3, 4 行目: 種類ごとの値
```

| 種類 | 3 行目 | 4 行目 | 働き |
| --- | --- | --- | --- |
| `station` | 駅名 | 停車秒数・向き (`continue` / `reverse` / `north` など)・`power` (信号まで待つ)・`head` / `center` / `tail`・`speed=速さ` | 列車を止めて待ち、発車させる。駅名は行き先の名前にもなる。停車中は周りのレバーを入れる |
| `destination` | この場所の名前 | 次の行き先 | 経路探索の行き先になる。着いた列車に次の行き先を渡す |
| `switcher` | `向き:条件` | `向き:条件` | 列車が来る前にレールの形を変える。向きは `left` / `right` / `straight` / `n` / `e` / `s` / `w`。条件は `tag=急行`、`@東京` (行き先)、`name=列車名`、`!` で否定、`&` で両方。どれにも当たらず列車に行き先があれば、経路探索で決める |
| `launch` | 速さ | 向き・加速度 | その速さまで加速する |
| `speed` | 最高速度 | | 最高速度を変える |
| `property` | `名前 値` | `名前 値` | 設定を変える (下の一覧) |
| `tag` | `+付ける -外す =置き換える` | 続き | タグを付け外しする |
| `route` | 行き先を空白で区切る | 続き | 順に向かう行き先を決める |
| `blocker` | | | 信号があるあいだ手前で止める (`[!train]` で逆) |
| `wait` | 空いているべき距離 | 空いてから待つ秒数 | 前の列車が離れるまで待つ |
| `mutex` | 区間の名前 | `enter` / `leave` | 入口から出口まで 1 本の列車しか入れない |
| `teleport` | 移る先の出入口の名前 | この出入口の名前 | 列車を別の場所 (別のワールドでもよい) の出入口へ移す。2 行目に向きを足せる |
| `spawn` | 保存した列車の名前 | 向き・速さ | 信号が来たら列車を出す |
| `destroy` | 条件 (省略可) | | 列車を消す |
| `reverse` | 条件 (省略可) | | 列車の向きを反対にする |
| `skip` | 枚数 | 条件 | この先の看板をいくつか無視させる |
| `eject` | | | 乗客を降ろす |
| `enter` | 半径 | | 近くのプレイヤーを乗せる |
| `announce` | 文章 | 文章 | 乗客にメッセージを出す (2 行目に `title` で画面の中央) |
| `sound` | 音の名前 | 音量 高さ | 音を鳴らす (2 行目に `world` で周りにも) |
| `effect` | パーティクルの種類 | 数 | パーティクルを出す |
| `detector` | 条件 (省略可) | | 列車がいるあいだ周りのレバーを入れる |

`/tt signs` でも一覧を見られます。看板を置くと書き方を確かめ、間違っていれば理由を出して置けないようにします。

## 列車の設定

`/tt property <名前> <値>` と `property` の看板で変えます。

| 名前 | 内容 |
| --- | --- |
| `speedlimit` | 最高速度 |
| `acceleration` / `deceleration` | 加速度・減速度 (発車、駅での停車、マスコン) |
| `friction` | 1 tick ごとに失う速さの割合 |
| `gravity` | 坂で重力を受けるか (止まると転がり落ちる) |
| `waitdistance` | 前の列車と空ける距離 |
| `coupling` | ぶつかった列車と連結するか (両方が true のとき) |
| `keepchunksloaded` | 走っているあいだ周りのチャンクを読み込んだままにするか |
| `manualcontrol` | マスコンで運転できるか |
| `derail` | 線路の終わりで止まらずに外れて進むか (新しい列車の既定は `config.yml` の `train.derail`) |
| `allowenter` / `allowexit` | 乗れるか・降りられるか (`/tt cart property` で車両ごと) |
| `invincible` | 管理者以外は (持ち主でも) 消せないか |
| `destination` / `route` / `name` | 行き先・経路・案内に使う名前 |

## ブロックを列車にする

ワールドに建てたものを、そのまま車両にできます。

1. `/tt wand` で範囲を選ぶ道具を受け取り、左クリックと右クリックで範囲の角を選びます (`/tt pos1`、`/tt pos2` でも選べます)。範囲の中か真下に線路が必要です。
2. 前にしたい向きを見ながら `/tt blocks convert [名前]` を実行すると、ブロックが消えて同じ見た目の列車になります。線路は消えません。
3. 走らせたあと、止めて `/tt blocks restore` を実行すると、今いる場所にブロックとして戻ります。向きは 90 度ごとに合わせます (カーブを曲がったあとは、ブロックの向きも回ります)。置く場所にブロックがあればやめます (`force` で上書き)。

`/tt blocks capture <名前>` は範囲をモデルとして保存するだけで (ブロックは消しません)、`/tt model blocks <名前>` でどの車両の見た目にもできます。

**ブロックのデータは失われません。** ブロックはストラクチャーブロックと同じ形式 (NBT) で `models/<名前>.nbt` に保存するので、看板の文字、チェストの中身、ブロックの向きなどがそのまま戻ります。

### MarumaSign の看板

[MarumaSign](https://github.com/TORO-Server/MarumaSign) の形式で書かれた看板は、列車の上でも MarumaSign の画像・3D モデルとして見えます。

ブロックのディスプレイは看板の文字を描かないので、看板の文字をデータに持つ看板のアイテムを、アイテムのディスプレイに入れて描きます。MarumaSign はそのアイテムを看板と同じ絵で描くので、看板に書かれた位置・大きさ・回転をディスプレイの変換で再現して、ワールドに置いた看板と同じ見た目にします。この計算が MarumaSign の描き方と一致することは、テスト (`MarumaSignTransformTest`) で確かめています。

- 吊り看板は MarumaSign が描かないので、ふつうの看板として描きます。
- 壁掛けの看板の 3D モデルは、モデルの奥行きによって MarumaSign が壁からの距離を変えるため、少しずれることがあります (画像はずれません)。
- 絵が裏返って見えるときは、`config.yml` の `render.marumasign-item-flip` を `false` にしてください。

ふつうの看板は、板をブロックのディスプレイで、文字を文字のディスプレイで描きます (文字の色と光る文字も写します)。

## 自由な線路

ノードを置いて結ぶと、その間が滑らかな曲線の線路になります。坂やカント (車体の傾き) も付けられ、レールの端と同じ場所に置いたノードはバニラのレールにつながります。

| コマンド | 内容 |
| --- | --- |
| `/tt track add [here\|rail\|nolink]` | 見ているブロックの上 (`here` は足元、`rail` は見ているレールの端) にノードを置き、前のノードとつなぐ |
| `/tt track select [ID]` | 近くのノードを選ぶ |
| `/tt track link <a> [b]` / `unlink <a> [b]` | ノードをつなぐ・切り離す |
| `/tt track move` / `remove` | 選んだノードを足元へ動かす・消す |
| `/tt track dir [auto]` | 線路の向きを見ている向きにする (`auto` で自動) |
| `/tt track roll <度>` | 車体の傾き |
| `/tt track name <名前>` | 行き先の名前を付ける |
| `/tt track switch <来るノード> <進むノード>` | 分岐の向き (レールから来るときは 0) |
| `/tt track show [秒]` | 線路をパーティクルで見せる |

分岐で行き先がある列車は、経路探索で向きを選びます。

## コマンド

`/tt` (`/toro-train`、`/torotrain`) で使います。対象の列車は、乗っている列車、`/tt select` で選んだ列車、近くの列車の順に決まります。コンソールやコマンドブロックからは `/tt select <名前>` で選び、`at <x> <y> <z> [ワールド] [向き]` で場所を指定できます。

| コマンド | 内容 |
| --- | --- |
| `create [両数] [ブロック] [at ...]` | 列車を出す |
| `spawn <保存名> [速さ] [at ...]` / `save <名前>` / `saved [delete <名前>]` | 保存した列車 |
| `list` / `info` / `select [名前\|nearest]` | 列車の一覧・情報・選択 |
| `destroy` / `destroyall [ワールド]` | 列車を消す |
| `speed <速さ>` / `launch <速さ> [加速度]` / `stop` / `reverse` | 動かす |
| `property <名前> [値]` / `cart property <名前> [値]` | 設定 |
| `dest <行き先>` / `route <行き先...>` / `dests` | 行き先と経路 |
| `tag add\|remove\|clear <タグ>` / `cart tag ...` | タグ |
| `name <名前>` / `split <何両目から>` | 名前・切り離し |
| `enter` / `exit` / `cart eject` | 乗る・降りる・降ろす |
| `model default [ブロック]` / `model blocks <名前>` / `model item [大きさ]` / `model yaw <度>` / `model offset <x> <y> <z>` / `model length <長さ>` | 車両の見た目 (`item` は手に持ったアイテム。リソースパックのモデルも使える) |
| `wand` / `pos1` / `pos2` / `blocks capture\|convert\|restore` / `models [delete <名前>]` | ブロックの列車 |
| `track ...` | 自由な線路 |
| `signs` / `reload` / `saveall` | 看板の一覧・再読み込み・保存 |

## 保存するファイル

`plugins/TORO-Train/` に保存します。

| ファイル | 内容 |
| --- | --- |
| `config.yml` | 設定 |
| `trains.yml` | 走っている列車 (位置、速さ、車両、設定)。終了時と一定時間ごとに保存 |
| `saved-trains.yml` | 保存した列車 |
| `tracks.yml` | 自由な線路のノード |
| `names.yml` | 行き先と出入口の名前 |
| `models/` | ブロックのモデル (`.nbt` と `.yml`) |

線路が変わって列車を元の場所に戻せないときは、覚えていた先頭の位置に最も近い線路に置き直します。ワールドがないなどで戻せない列車は、消さずに `trains.yml` に残します。

## まだないもの

TrainCarts の次の機能は、まだ作っていません。

- 車両の見た目を組み立てる画面 (アタッチメントのエディタ) とアニメーション
- チェストとアイテムをやりとりする看板 (collect / deposit / crafter など)
- 切符の仕組み
- 生き物を乗せること
- TrainCarts の保存データの読み込み
- 天井に付けた逆さまのレール (TrainCarts の allowUpsideDownRails)

## 開発

```bash
./gradlew build
```

`build/libs/TORO-Train-<バージョン>.jar` ができます (Kotlin の標準ライブラリはパッケージを移して同梱)。`./gradlew test` で、線路の道のりの計算と、MarumaSign の看板の位置合わせのテストを行います。
